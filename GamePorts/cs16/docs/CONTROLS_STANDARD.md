# Planned Counter-Strike 1.6 Switch controls

This mapping describes the proposed engine integration. The current release has launcher navigation and WAD validation.

| Input | Action |
| --- | --- |
| ZR / ZL | Primary / alternate attack |
| R / L | Reload / jump |
| Left stick | Move |
| Right stick / gyro | Aim / fine aim correction |
| B / A | Crouch / interact |
| Y / X | Last weapon / buy menu |
| D-pad up | Flashlight or night vision, where available |
| D-pad left and right | Team radio |
| Plus / Minus | Pause menu / scoreboard |

The [port record](../PORT.md) includes the planned touch and keyboard/mouse mappings. Test focus loss, device changes, settings persistence, remapping, and live prompts after integrating the engine.
