# Acceptance scenarios: rts

Run each in every declared input mode, in handheld (720p, touch) and in docked (1080p, no touch screen). Record pass/fail, the console mode, and where it ran (host, emulator, physical Switch).

## Select a unit, then order it to move (`select_and_command`)

- [ ] gamepad: Move pointer with left stick, A to select, X to command
- [ ] touch: Tap the unit, long-press the ground
- [ ] kbm: Left click the unit, right click the ground

## Move the camera across the map (`camera`)

- [ ] gamepad: Right stick
- [ ] touch: Drag with two fingers
- [ ] kbm: Mouse at screen edge or W A S D

## Zoom in and out (when zoom is enabled) (`zoom`)

- [ ] gamepad: ZL and ZR
- [ ] touch: Pinch
- [ ] kbm: Mouse wheel

## Select several units (`box_select`)

- [ ] gamepad: Hold ZR and move the stick
- [ ] touch: Drag with one finger on empty ground
- [ ] kbm: Drag with left button

## Open the menu and cancel with the same device (`menu`)

- [ ] gamepad: + then B
- [ ] touch: Menu button then back
- [ ] kbm: F10 then Esc
