# Changelog

## 1.0.1

- Launcher rebuilt with the Port Studio standard: hero card, Overview (quick settings and game folder), How to play and Files tabs, Show FPS switch, "Engine not linked" badge.
- The Play button is replaced by Verify Files, because there is no game engine to start yet.

## 1.0.0

- Added initial native launcher and file verification preview for Age of Empires II on Nexvyn OS 1.3.28-beta.2, Native SDK 1.2, and ABI 1.
- Integrated RTS experience profile (`rts`) with touchscreen gesture mappings, gamepad cursor/box selection, and keyboard/mouse controls.
- Added data verification for `data/graphics.drs`, `data/empires2.dat`, and game executables.
- Added localized interface in all 8 required SDK locales (en, tr, de, es, fr, ja, ko, zh).
